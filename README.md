# Industrial-Client-Retention-Assignment
Машинско учење: Домашна работа 1 , Churn Prediction Analysis
Ова е моето решение за првата домашна задача по предметот **Машинско учење (2025/26)** на ФЕИТ. 

## Опис
Задачата се фокусира на изработка на модел за предвидување дали индустриски клиенти би го раскинале договорот за одржување на опремата. Целта беше да се анализат карактеристиките на клиентите и да се развие систем кој ќе ги идентификува оние со висок ризик од заминување.

## Содржина
- `Елаборат_Домашна1.ipynb`: Јупитер тетратка со комплетна анализа на податоците, препроцесирање, избор на модел и евалуација на резултатите преку F1-score.
- `requirements.txt`: Листа на користени библиотеки.
